THE PROJECT

For this project, I analyzed more than 8,800 Netflix titles using Microsoft Excel to explore trends across content type, ratings, countries, release years, and movie lengths. I worked with the dataset to identify patterns within Netflix's content catalog and better understand how its content varies across different categories and time periods.

I then created an interactive dashboard using Excel PivotTables, KPI metrics, and data visualizations to organize the information and present my findings in a clear and meaningful way. This project allowed me to transform a large dataset into useful insights while strengthening my skills in data analysis, data visualization, and using Excel to communicate information effectively.
